**What this delivers:** The installed app (added to your home screen) will start picking up new versions on its own — no more removing and re-adding it to get updates. Fully closing and reopening the app loads the newest version right away, with nothing to do. If a new version is published while you're already using the app, a small "new version available" message appears that you can tap whenever you're ready; it won't interrupt what you're reading.

**Status:** Not ready: we found a case where that "new version available" message might not show up correctly when you switch back to the app after it's been in the background — it could update silently instead of asking you first. We're fixing that before this is ready for you to check.
